# 문제 해결

[English](TROUBLESHOOTING.md) · [한국어](TROUBLESHOOTING.ko.md)

## 첫 설치 중 자동 재부팅

첫 설치 시 부팅 이미지 이후 검정화면이 나오는 것은 정상입니다. 전원을 켜 둔 채
약 5분 기다리면 한두 차례 자동 재부팅한 뒤 메뉴가 표시됩니다. 이 설치 과정에서는
걱정하지 않으셔도 됩니다. SHARE 확장과 S12 설정 설치로 인한 재부팅이며,
일반적인 게임 실행·종료에는 재부팅이 필요하지 않습니다.

## Wi-Fi가 꺼져 있거나 PortMaster 다운로드가 안 될 때

공개판은 Wi-Fi가 꺼져 있고 개인 네트워크 정보가 없는 상태로 시작합니다.
일반 설정에서 Wi-Fi를 켜고 SSID와 비밀번호를 입력해 주세요. PortMaster는 Ports의
설치 항목으로 설치합니다. 배포판에는 개인적으로 내려받은 PortMaster 앱 데이터를
미리 설치해 두지 않았습니다.

## PSP 종료와 HOME 버튼

SELECT+START를 약 1초간 함께 눌러 주세요. 상단의 HOME키를 이용한 에뮬레이터 종료는
RetroArch에서 작동하며 PPSSPP에서는 비활성화되어 있습니다. PPSSPP는 종료 중 멈춤과
대체 경로로 복구되는 문제가 있어 이 기능을 꺼 두었습니다.
PPSSPP에서 HOME이 작동하지 않는 것을 입력 드라이버 누락으로 판단하지 마세요.

## 업데이트 후 PortMaster 화면이 옆으로 나올 때

PortMaster 실행기는 시스템 전체 SDL 교체가 아니라 전용 PySDL2 DLL을 선택합니다.
에뮬레이터 실행 준비 단계에서 설치·업데이트 후에도 알려진 실행기 설정을 다시 적용합니다.
상위 프로젝트가 셸 스크립트 형식을 바꿨다면 시스템 전체 SDL을 교체하기보다 실행기
버전과 오류를 알려 주세요. 이 보정으로 다른 모든 포트의 렌더링 경로까지 시험한 것은 아닙니다.

## 검정화면 또는 이전 그래픽 모드로 실행될 때

먼저 무결성이 확인된 이미지와 정상 SD 카드를 사용해 주세요. Mali 복구가 요청되었거나
자동 시작 시도가 실패했는지 확인해야 합니다. 대체 메뉴에서는 정상 Vulkan 경로를
제공하지 않습니다. 복구하려면 BOOT에 빈 `DISABLE_MALI.txt` 파일을 만들고 재시작합니다.
같은 이미지에서 나온 복구 백업을 유지하고, 예전 시험 스크립트·관계없는 Mali 모듈·
현재 설정을 섞지 마세요.

## 밝기 방향이 바뀔 때

최종 수정은 부팅과 절전 복귀에서 실제 하드웨어 극성을 정상화합니다. 별도의 숫자 반전을
추가하지 마세요. PWM 정상화 로그, 실행 중 PWM 인자, 완전히 껐다 켠 뒤인지 절전
복귀 뒤인지가 원인 구분에 도움이 됩니다. 보고 전에 SSID, 비밀번호, MAC 주소 등
개인정보를 지워 주세요.

## 문제 보고

배포 파일 이름과 체크섬, 기기 모델, 에뮬레이터·백엔드, 정확한 발생 조건,
절전 전후 발생 여부와 메뉴 복귀 여부를 알려 주세요. 개인 설정 디렉터리 전체나
게임 파일은 업로드하지 마세요.

## v1.0.1 Wi-Fi 진단

Wi-Fi가 실패하면 그 부팅 상태를 유지한 채 tools/ActionPi-WiFi-Diagnostic.sh를 SHARE/roms/ports에 복사해 실행합니다. 메뉴가 나온 뒤 약 2분 기다려도 실패할 때 수집하고, Wi-Fi를 껐다 켜거나 재부팅하기 전에 실행해 주세요. 검색·켜기/끄기·서비스 재시작·하드웨어 리셋은 하지 않습니다. 같은 폴더에 시각이 붙은 ZIP이 생깁니다. 최초 정상 부팅과 재부팅 후 실패 자료를 함께 주면 비교에 도움이 됩니다. SSID·암호·MAC·IP·원본 설정·원본 dmesg는 제외합니다. helper 파일이 있다는 것만으로 실행된 것은 아니므로 실제 시작 코드 해시도 함께 확인합니다.
