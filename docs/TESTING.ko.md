모든 게임, 모든 PortMaster 포트, 모든 에뮬레이터 백엔드, 모든 절전 상황,
드라이버 ABI의 모든 동작이나 다른 보드 변형을 시험했다고 주장하지 않습니다.
Flycast 스탠드얼론의 HOME 종료는 아직 확인하지 않았습니다. 셰이더 캐시 존재,
모듈 로드, Vulkan 장치 인식, 프레임버퍼 제출과 실제 보이는 게임 화면은 서로 다른
확인 단계이며 작업 이력에서도 구분합니다.

커널 수정의 ARM64 모의 실행 검증은 일부 함수 호출, 오류 경로, 호출된 함수가 보존해야
하는 상태와 정리 순서를 확인합니다. 기기 전체, 메모리 할당기, 동시 실행,
전원 관리나 실제 패널의 전기적 동작까지 모의하는 것은 아닙니다.
